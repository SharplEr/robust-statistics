Hyndman–Fan · types 1, 7, 8

Как получен quantile?

Один target \(Q(p)\), разные правила оценивания по конечной выборке.

Ранги и интерполяция

Отсортируй \(x_{(1)}\le\cdots\le x_{(n)}\). Для type 1: \(\widehat Q_1(p)=x_{(\lceil np\rceil)}\), \(0<p\le1\). Для types 7/8:

\[j=\lfloor h\rfloor,\quad g=h-j,\quad\widehat Q(p)=(1-g)x_{(j)}+g x_{(j+1)}.\]
TypeПозиция hNumPy method
1Ранг \(\lceil np\rceil\)inverted_cdf
7\(1+(n-1)p\)linear
8\((n+\frac13)p+\frac13\)median_unbiased

Для types 7/8 при \(h\le1\) — минимум, при \(h\ge n\) — максимум. При \(n=1\) — единственное значение. При \(p=0\) все три метода продолжаем минимумом. Ранги в формулах начинаются с 1.

Контрольный пример

Для [12,14,15,18,20,23,26,80], p90: type 1 = 80, type 7 = 42.2, type 8 = 71. Не выше 42.2 находятся 7 из 8 значений, то есть 87.5%: интерполированная оценка population p90 не обязана быть inverse ECDF.

Почему type 8 и когда работает

Для непрерывной F: \(F(X_{(k)})\sim\operatorname{Beta}(k,n+1-k)\). Сетка type 8 приближает медианы этих вероятностных позиций, затем интерполирует между узлами. При n=8 точная медианная позиция максимума ≈0.917004, сетка даёт 0.92. Это не точная несмещённость.

Состоятельность: для i.i.d., фиксированного \(0<p<1\) и конечного q с \(F(q-\varepsilon)<p<F(q+\varepsilon)\) для любого \(\varepsilon>0\) оценки types 1/7/8 сходятся по вероятности к q. Линейность F/Q не требуется; малая ошибка при данном n не гарантирована. При плоском участке CDF на уровне p, уходящем к 1 уровне или зависимости нужен отдельный анализ.

Границы вывода

Плавность по p не гарантирует малую MSE или robustness. Положительный вес максимума допускает разрушение большой заменой. Истинный quantile может лежать за наблюдаемым диапазоном.
