Trimmed HD · три гарантии

Нули, ранги, условия.

Ширина D не равна сохранённой массе Z. Устойчивость не равна точности.

Построение

\(a=(n+1)p\), \(b=(n+1)(1-p)\). HDI [L,R] максимизирует массу Beta при заданной ширине D=R−L. \(Z=I_R(a,b)-I_L(a,b)\).

\[\begin{aligned}c_i&=\max((i-1)/n,L),\quad d_i=\min(i/n,R),\\\widetilde w_i&=\begin{cases}(I_{d_i}-I_{c_i})/Z,&c_i<d_i,\\0,&c_i\ge d_i,\end{cases}\qquad\widehat Q=\sum_{i=1}^{n}\widetilde w_iX_{(i)}.\end{aligned}\]

Граничные ячейки частичны; n и Beta-параметры исходные. D=1/√n — эвристика.

1. Конечная устойчивость: без модели F

\[\ell=\lfloor nL\rfloor+1,\quad r=\lceil nR\rceil,\quad\varepsilon_n^*=\frac{\min(\ell,n-r+1)}{n}.\]

Для фиксированных весов: вверх разрушают n−r+1 замен, вниз — ℓ. Меньше замен сохраняют ограниченность; ошибка всё ещё возможна. n=9, p50, D=1/3: ранги 4–6, breakdown=4/9. Если R=1, максимум остаётся: верхний порог — одна замена.

2. Состоятельность: нужна локализация

Достаточно: i.i.d.; фиксированный внутренний p; конечный q=Q(p); \(F(q-\varepsilon)<p<F(q+\varepsilon)\) для всех ε>0; нормированные неотрицательные веса внутри детерминированного окна Lₙ,Rₙ→p. Зажимаем оценку между крайними используемыми рангами. Для HDI достаточно Dₙ→0, поскольку его mode→p.

Конечные моменты X не нужны для этого вывода. Сходимость MSE отсюда не следует.

3. Конечная ошибка: counts и локальная density

Дополнительно \(F(q)=p\), density f≥c>0 на всём [q−ε,q+ε]. Пусть \(\rho_n=\max(|\ell/n-p|,|(r-1)/n-p|)\). Если cε>ρₙ:

\[\mathbb P(|\widehat Q-q|>\varepsilon)\le2e^{-2n(c\varepsilon-\rho_n)^2}.\]

Следует из Hoeffding для независимых indicators X≤q±ε. F и c неизвестны: это условная теоретическая гарантия, не готовый интервал по данным. При зависимости требуется другой контроль. Положительное ρₙ/c не является нижней границей ошибки. Лучшая MSE не гарантирована.
