Для печати · один target, два вида ошибки

IF и точность.

Один target θ; явно заданные модель и загрязнение.

Bias, variance, MSE

\[\operatorname{MSE}(\widehat\theta;\theta)=\operatorname{Var}(\widehat\theta)+\operatorname{Bias}(\widehat\theta)^2\]

Bias (смещение): \(\mathbb E[\widehat\theta]-\theta\). Variance (дисперсия) — разброс вокруг E[θ̂]. MSE (среднеквадратичная ошибка) учитывает оба; нужен конечный второй момент оценки.

Influence function (функция влияния)

\[\operatorname{IF}(z;T,F)=\lim_{\varepsilon\downarrow0}\frac{T((1-\varepsilon)F+\varepsilon\delta_z)-T(F)}{\varepsilon}\]

\(\delta_z\) — Dirac measure (мера Дирака), point mass в \(z\); соответствует обобщённой дельта-функции \(\delta(x-z)\). Её CDF: \(\mathbf1\{z\le x\}\). Локальное изменение T ≈ ε·IF(z). Дифференцируем population functional.

FunctionalIF при чистом F
Mean μ\(z-\mu\); не ограничена по \(z\)
Quantile q=Q(p)\(\dfrac{p-\mathbf1\{z\le q\}}{f(q)},\ z\ne q\)
Median m\(\dfrac{\operatorname{sign}(z-m)}{2f(m)},\ z\ne m\)

Для quantiles: непрерывная положительная density f около q. IF ограничена при фиксированном F, но может быть велика при малой f(q). \(\mathbf1\{z\le q\}\) равен 1 при \(z\le q\), иначе 0. IF — локальный отклик; breakdown — конечное разрушение.

Efficiency (эффективность) зависит от F

Для mean/median при i.i.d. и условиях регулярности: \(\sqrt{n}(\widehat\theta_n-T(F))\xrightarrow{d}\mathcal N(0,V)\), где \(V=\mathbb E_{X\sim F}[\operatorname{IF}(X;T,F)^2]\). Ориентир для variance оценки — V/n.

\[F=\mathcal N(\theta,\sigma^2):\quad V_{\mathrm{mean}}=\sigma^2,\quad V_{\mathrm{median}}=\frac{\pi\sigma^2}{2},\quad\operatorname{ARE}=\frac2\pi.\]

Median требует примерно в 1.57 раза больше чистых normal наблюдений для той же асимптотической точности. Загрязнение меняет сравнение; относительно чистого θ учитывай также bias.

Определение IF: Wasserman, Lecture 19, §3. Quantile limit: Geyer, §7.4. MSE decomposition.
